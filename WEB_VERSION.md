## Troubleshooting

### File won't open?
- Right-click → "Open with" → Select Chrome/Firefox
- Or drag file into browser window

### Bookmarks/History lost?
- Browser LocalStorage cleared
- Save important bookmarks elsewhere
- Avoid "Clear Cache" if you want to keep data

### Slow performance?
- Clear browser cache (Settings → Storage)
- Close other tabs
- Restart browser

### Can't access websites?
- This is simulated - actual web requests won't work
- Use Desktop Version for real internet access
- Use [Web API](../API.md) for programmatic access
